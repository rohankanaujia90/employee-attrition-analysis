# Employee Attrition Analysis

**ABES 2nd Year B.Tech Data Analyst Project #10** (HR and education domain)

Repository: https://github.com/rohankanaujia90/employee-attrition-analysis

Analyse why employees leave a company using the IBM HR Attrition dataset.
Python cleans and profiles the data, Oracle SQL models and queries it, and a Power BI dashboard
shows attrition by department, tenure, salary band and gender.

## Tech stack

| Layer | Tool | What it does here |
|---|---|---|
| Cleaning and EDA | Python 3 + pandas | Data-quality checks, salary/tenure/age bands, clean CSV, data-quality report |
| Storage and analysis | Oracle Database (XE 21c) + SQL Developer | Star schema, `GROUP BY` attrition queries, `RANK`, views for Power BI |
| Visualisation | Power BI Desktop | KPI cards, driver charts, department and gender slicers, drill-down |

## Setup (one time)

1. **Python 3.12**: `winget install Python.Python.3.12` (or python.org). Tick "Add to PATH".
2. **Python packages** (from the project root): `pip install -r python/requirements.txt`
3. **Oracle Database 21c XE** and **SQL Developer** from oracle.com (both free).
4. **Power BI Desktop** from the Microsoft Store (free).
5. **Git**: `winget install Git.Git`
6. **Dataset**: download *IBM HR Analytics Employee Attrition & Performance* from Kaggle
   (https://www.kaggle.com/datasets/pavansubhasht/ibm-hr-analytics-attrition-dataset)
   and save `WA_Fn-UseC_-HR-Employee-Attrition.csv` into `data/raw/`.

## How to run

```powershell
# 1. Clean + profile: open the notebook and Run All (writes data/clean/hr_attrition_clean.csv) ...
jupyter notebook python/Employee_Attrition_Analysis.ipynb
#    ... and run the script for the data-quality report (reports/data_quality_report.md)
python python/01_clean_and_profile.py

# 2. In SQL Developer (connected as your schema user), run sql/01_ddl.sql

# 3. Load the clean CSV into staging (run from the project root)
sqlldr userid=YOUR_USER/YOUR_PASSWORD@localhost/XEPDB1 control=sql/02_load_staging.ctl log=reports/sqlldr.log

#    (No SQL*Loader? Right-click STG_HR_EMPLOYEE in SQL Developer -> Import Data -> pick the clean CSV.)

# 4. In SQL Developer, run in order:
#    sql/03_transform_load.sql, sql/05_views.sql, sql/06_validation_checks.sql, sql/04_analysis_queries.sql

# 5. Build the dashboard by following docs/03_powerbi_build_guide.md
```
